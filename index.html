10ª classe

Funções e generalidades

Uma função associa a cada valor de x um único valor de y. O domínio é o conjunto de valores permitidos para x.

Exemplo: f(x) = 2x + 1. Para x = 3, temos f(3) = 2(3) + 1 = 7.
Exercício resolvido

Dada f(x) = 3x − 4, calcule f(5).

f(5) = 3(5) − 4 = 15 − 4 = 11

Equações do segundo grau

Uma equação da forma ax² + bx + c = 0 resolve-se com a fórmula resolvente: x = (−b ± √(b²−4ac)) / 2a.

Exemplo: x² − 5x + 6 = 0 → a=1, b=−5, c=6. Δ = 25−24 = 1. x = (5±1)/2 → x=3 ou x=2.
Exercício resolvido

Resolva: x² − 7x + 10 = 0

a=1, b=−7, c=10
Δ = 49 − 40 = 9
x = (7 ± 3) / 2 → x = 5 ou x = 2

Trigonometria no triângulo retângulo

Seno, cosseno e tangente relacionam ângulos e lados de um triângulo retângulo.

Exemplo: sen θ = cateto oposto / hipotenusa. Se o oposto mede 3 e a hipotenusa mede 5, sen θ = 3/5 = 0,6.
Exercício resolvido

Num triângulo retângulo, o cateto adjacente mede 8 e a hipotenusa mede 10. Calcule cos θ.

cos θ = adjacente / hipotenusa = 8/10 = 0,8

11ª classe

Progressões aritméticas

Numa progressão aritmética (PA), cada termo é obtido somando uma razão constante (r) ao termo anterior. Termo geral: aₙ = a₁ + (n−1)·r

Exemplo: PA (2, 5, 8, 11, ...), a₁=2, r=3. O 6º termo: a₆ = 2 + (6−1)·3 = 2+15 = 17.
Exercício resolvido

Numa PA, a₁ = 4 e r = 5. Calcule o 10º termo.

a₁₀ = 4 + (10−1)·5 = 4 + 45 = 49

Limites de funções

O limite descreve o valor para o qual uma função se aproxima quando x se aproxima de um determinado ponto.

Exemplo: lim (x→2) (x² − 4)/(x − 2). Fatorando: (x−2)(x+2)/(x−2) = x+2. Substituindo x=2: 2+2=4.
Exercício resolvido

Calcule lim (x→3) (x² − 9)/(x − 3)

(x²−9) = (x−3)(x+3)
Simplificando: x+3
Substituindo x=3: 3+3 = 6

Derivadas — noção introdutória

A derivada de uma função representa a taxa de variação instantânea. Regra básica: se f(x) = xⁿ, então f'(x) = n·xⁿ⁻¹

Exemplo: f(x) = x³ → f'(x) = 3x².
Exercício resolvido

Calcule a derivada de f(x) = 4x² + 3x

Derivando termo a termo:
d/dx(4x²) = 8x
d/dx(3x) = 3
f'(x) = 8x + 3
